# awesome-tools

A collection of small, practical tools I have built. Each tool lives in its own repository with install steps, usage and screenshots.

## Tools

| Tool | What it does | Built with |
| --- | --- | --- |
| [PDF Merger](https://github.com/sh-how/pdf-merger) | Combine PDFs into one file from a drag-and-drop terminal app | Python, Textual |
| [logsift](https://github.com/sh-how/logsift) | Search and filter many CSV, TSV and Excel log files at once from a drag-and-drop terminal app | Python, Textual |

### [PDF Merger](https://github.com/sh-how/pdf-merger)

Drag PDFs into the terminal window, put them in order, press Enter.

[![PDF Merger showing four PDFs ready to merge](https://raw.githubusercontent.com/sh-how/pdf-merger/main/screenshots/2-list.png)](https://github.com/sh-how/pdf-merger)

### [logsift](https://github.com/sh-how/logsift)

Drag a folder of CSV, TSV or Excel logs into the terminal window, type `src=10.1.1.5 action=drop`, and see matching rows from every file.

[![logsift filtering three firewall log files](https://raw.githubusercontent.com/sh-how/logsift/main/screenshots/1-filter.png)](https://github.com/sh-how/logsift)
